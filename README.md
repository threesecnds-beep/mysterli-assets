# mysterli-assets

Images for the SillyTavern character card 《米斯特利家族：霧鐘宅邸的家庭教師》.
The card loads them through jsDelivr at a fixed tag (for example `@v1`). Do not move an existing tag; push a new one instead.

- `cg/`: event illustrations (3:2, 1152×768 WebP)
- `outfit/`: outfit variants of the three sisters (2:3, 512×768 WebP)
- `bg/`: location backgrounds (3:2, 1152×768 WebP)
